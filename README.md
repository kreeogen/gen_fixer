# gen_fixer

---

## 🇬🇧 English

**gen_fixer** is a low-level general plug-in for Winamp 2.95 that modifies the behavior of this retro version, adapting its functionality to modern standards.

The project makes it possible to use Winamp 2.95 on modern versions of Windows almost the same way it was used back in the Windows 98–XP era.  
Special attention is given to proper **Unicode and Cyrillic support**.

---

### Fixed and added features

- Winamp no longer starts minimized from time to time  
- The icon in the settings dialog title bar no longer disappears  
- Added a **“Restart Winamp”** menu item  
- Added a keyboard shortcut for the **Mute** function  
- Playlist buttons replaced with a Winamp 5 Modern–style menu  
- Added cover art removal and renaming features  
- Modified Windows Explorer context menu for setting cover art  
- Fixed Cyrillic text rendering when playing video in fullscreen mode  
- Cyrillic Unicode tags are now displayed correctly in:
  - Playlist  
  - Media Library  
  - Internet Radio  
- Fixed incorrect handling of custom ID3v2 frames  
- Media Library now correctly searches for Cyrillic names  
- Media Library icons now automatically adjust their tint when cover art changes  
- Added **ClearType font smoothing**  
  *(Windows XP and newer only)*  
- Added support for:
  - **.m3u8** playlists  
  - Unicode-encoded **.pls** playlists  
- Media Library and Playlist fonts are now synchronized  

---

### Build

- Visual Studio 2003  
- Windows XP and newer (tested)

## 🇷🇺 Описание (RU)

**gen_fixer** — это низкоуровневый general-plug-in для Winamp 2.95, который изменяет поведение этой ретро-версии, адаптируя её функциональность под современные стандарты.

Проект позволяет использовать Winamp 2.95 на современных версиях Windows почти так же, как это было во времена Windows 98–XP.  
Особое внимание уделено корректной работе с **Unicode и кириллицей**.

---

### Что исправлено и добавлено

- Winamp больше не запускается в свёрнутом виде время от времени  
- Иконка в заголовке диалога настроек больше не пропадает  
- Добавлен пункт меню **«Перезапустить Winamp»**  
- Добавлено клавиатурное сочетание для функции **Mute**  
- Кнопки плейлиста заменены на меню в стиле Winamp 5 Modern  
- Добавлены функции удаления и переименования обложек  
- Изменён пункт контекстного меню Проводника для установки обложки  
- Исправлено отображение кириллицы при воспроизведении видео в полноэкранном режиме  
- Кириллические Unicode-теги теперь корректно отображаются в:
  - Плейлисте  
  - Медиатеке  
  - Интернет-радио  
- Исправлено некорректное сохранение кастомных фреймов в тегах ID3v2  
- Медиатека теперь корректно ищет кириллические названия  
- Иконки в Медиатеке автоматически меняют оттенок при смене обложки  
- Добавлено сглаживание шрифтов **ClearType**  
  *(Windows XP и более новые версии)*  
- Добавлена поддержка плейлистов:
  - **.m3u8**
  - **.pls** в кодировке Unicode  
- Шрифт Медиатеки и шрифт Плейлиста синхронизированы
