# Winamp PE

General plug-in for Winamp 2.95 based on usability and Unicode support.

## Goals
- Preserve classic Winamp 2.95 behavior
- Improve Unicode tag handling
- Fix many modern OS compatibility issues

## What this is NOT
- Not a replacement for Winamp 5
- Not a competitor to WACUP

## Build
- Visual Studio 2003
- Windows XP+ (tested)

## Legal
This project does not include Winamp source code.
